# Data licensing and admission

Repository licensing does not relicense third-party data.

Review each external source at the exact provider/product/version/query level. Treat these as separate questions: access, commercial use, raw redistribution, derived redistribution, attribution, derivative/share-alike/database obligations, privacy and contractual restrictions.

`unknown`, stale, contradictory or ambiguous rights are blocking. Public availability is evidence of access, not permission to publish bytes.

Default workflow: metadata-only issue -> authoritative terms evidence -> rights decision -> scientific fitness review -> explicit artifact scope -> acquisition outside Git -> exact byte/hash identity -> transformation lineage -> optional publication only if the exact scope permits it.

Never use customer, claims, portfolio, treaty or confidential exposure data as a public fixture. De-identification alone does not make confidential data synthetic.
