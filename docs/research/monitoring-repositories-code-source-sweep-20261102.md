# World Monitor-like repositories: full code/source discovery pass — 2026-11-02

**Scope:** All twelve explicitly shortlisted public monitoring, event, response and disaster-management repositories from the prior source survey were checked against their GitHub default-branch trees. Representative source acquisition code, source lists, provider APIs and upstream documentation were read. This is a **source-inventory pass**, not a statement that every application code line or live endpoint was executed. An audited code reference is evidence of an intended input, not evidence of a successful API response or reuse rights.

## Method and registry

- Canonical non-admission source entries: [`landscape/sources-monitoring-repo-upstreams-20261102.json`](../../landscape/sources-monitoring-repo-upstreams-20261102.json) (**22 canonical entries in this shard**, from 23 historical research leads: 12 first-pass and 11 code-sweep leads, with the GLIDE ID preserved only in `landscape/sources-peer-cat-repositories-20261102.json` to avoid a global duplicate).
- World Monitor original provider candidates already exist in [`landscape/sources-worldmonitor-upstream-20261102.json`](../../landscape/sources-worldmonitor-upstream-20261102.json) (**18 candidates**). This new pass does not duplicate its existing identities.
- Other existing source shards already contain NASA FIRMS/EONET, USGS ComCat, GDACS, NHC, WMO warning systems, UNDRR DELTA/DesInventar, Sentinel-5P SO2, OpenStreetMap-derived exposure datasets, NOAA IBTrACS and various original flood/hazard sources. They are not copied again.
- Source discovery records remain `not_admitted`; exact provider/product, rights, commercial-use conditions, spatial/temporal meaning and scientific validity must be independently approved before ingestion/model runs.
- Verify duplicate provenance: five dashboards reusing USGS is **one** USGS observation source; WFP ADAM and GDACS/GloFAS/Shakemap are not independent impact truth if ADAM derives from the same inputs.

## Coverage gaps / do not silently claim completeness

- All twelve shortlisted repository *trees* were enumerated; relevant acquisition documentation/representative source implementation was checked. This is **not** exhaustive reading of every one of the thousands of World Monitor/DELTA/Sahana code files, or a live fetch of every RSS publisher.
- World Monitor 1,038 host rows include news, transports, caches and non-dataset URLs. The manifest cannot be equated with admitted sources or 1,038 distinct inputs. Keep the unfiltered manifest as a pointer and select named original providers by catastrophe-specific potential.
- MapAction dataset notes and the WFP ADAM official documentation disagree on present access; prefer new official provider documentation as the candidate discovery evidence, but **do not** claim API runtime success or rights until tested.
- LandScan, existing GloFAS, USGS ShakeMap, NASA FIRMS, FEMA and NOAA IBTrACS are already represented elsewhere in the source landscape. Distinguish original observations from re-packaged and downstream model outputs.
- More research opportunities **not automatically promoted:** InciWeb machine-readability, official JMA historical seismic catalog, WorldMirror strategic-asset source chain, WFP ADAM individual 13 OGC collections, older 2026 FloodScan licensing, and retained/archived emergency alerts.
