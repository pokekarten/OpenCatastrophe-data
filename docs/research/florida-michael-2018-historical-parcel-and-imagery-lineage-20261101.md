# Hurricane Michael: historical Florida parcel vintage and FEMA image-source lineage

**Reviewed 2026-11-01. Research-only.** The exact NOAA TIFF alpha mask in `docs/research/noaa-michael-seven-fema-alpha-mask-final-20261101.md` excludes visible-image validation for the **seven** corrected `DR-4399/RS/WI` FEMA point counts in one original NOAA tile. That does NOT invalidate FEMA's remote-sensing labels; it redirects the research to **the actual source imagery, temporal building context and independent measured damage**. No owner/address rows, parcel geometries, scene files, claims or buildings were downloaded/ingested in this branch.

## 2026 source-access correction: both former FGDL parcel ZIP editions removed

The historic FGDL 2017/2018 pages below document **metadata and source dates only**. A later original University of Florida GeoPlan notice dated **2025-10-08** explicitly confirms the **State GIS Office requested withdrawal of ALL historic and current FGDL parcel dataset files**. The public archive no longer lists `parcels_2017` or `parcels_2018` ZIPs. Thus the earlier tentative idea of a direct archived FGDL ZIP is superseded: those original source files are **not available from the present official FGDL distribution**, despite the preserved metadata.

GeoPlan directs users instead to the **different official 2025-labeled Florida DOR statewide cadastral FeatureServer**, whose *live geometry-free count-only* `where=1=1` returned **10,950,670 parcel polygon records** on 2026-11-01. It is not a historical 2017 pre-event dataset. Its layer holds personal owner/address fields and has a different current update history. Only its service metadata and aggregate count were checked, not parcel features. Complete official withdrawal, current state source identity and strict access gate are documented in `docs/research/florida-michael-2018-official-parcel-access-withdrawal-20261101.md`.

| **NICB Geospatial Intelligence Center / Vexcel** | [Original NICB 2018-11-05 statement](https://www.nicb.com/news/news-releases/video-shows-how-gic-imagery-transforming-catastrophe-response) confirms post-Hurricane Florence/Michael aerial imagery from Vexcel-equipped aircraft, delivered to GIC users | Alternate airborne imagery/possible evidence-source lead for the missing original FEMA `RS` image provenance | Individual flight and image date, exact tile area, archival scene ID/access route, redistribution rights and FEMA original image identity **unverified** |

FGDL is an **archive/discovery system**, not a snapshot timestamp guarantee for every spatial feature. Its 2017 and 2018 pages identify owner names, personal mailing/site addresses and parcel IDs. None are ingested or output by the research code. [FGDL's archive catalog](https://fgdl.org/explore-data/) describes an archive of older data layers; its documentation and metadata are accessible, but **we have not verified original ZIP/FGDB downloadable bytes or SHA-256**.

The underlying 2018-parcel statewide **geometry** and linked **tax-roll** may have different vintages. Source acquisition date, publication date, feature `SOURCEDATE`, actual build year and geometric capture date are all **distinct concepts**. They cannot be collapsed into one `event_as_of_date`. In particular, a post-hurricane tax record must not leak into a pre-event exposure/occupancy model.

## Original NOAA evidence points to multiple imagery families in the FEMA response

The NOAA NGS presentation **`NGS Emergency Response Imagery`**, Maryellen Sault, **April 2022**, shows a FEMA *Hurricane Michael Modeled Damage Assessments* web-map screenshot. Its layer menu lists named **NOAA Imagery** day/flight groups `20181011a_RGB`, `20181012a_RGB`, `20181012b_RGB`, `20181013a_RGB`, `20181014a_RGB`. It also shows different **`NCIB Imagery`** orthophoto categories with 2018-10-12/13 dates, e.g. `Pensacola to Panama City`, `Mexico Beach to Port St. Joe`, `South Pensacola`, `Chattahoochee to Thomasville`. The **slide actually spells `NCIB`**, whereas the 2018 news issuer is **NICB**. This is a **possible mapping, not a confirmed identity**: neither spelling similarity nor source-organization difference proves which original imagery labelled any specific FEMA feature.

Original NOAA deck: https://geodesy.noaa.gov/web/science_edu/presentations_library/files/2022_ngs_er_web.pdf (slide headed **FEMA Geospatial Damage Assessment**; source screenshot). This is historical source *visualization*, not an ArcGIS item-level `source_image_id`, raster checksum or dated independent validation. The screenshot's label **`Modeled Damage Assessments`** is not a reason to override the separately checked public `ASMT_TYPE=RS` provider group. Never mix dashboard labels with per-row source-native assessment methods.

[NOAA's emergency response FAQ](https://oceanservice.noaa.gov/hazards/emergency-response-imagery.html) explicitly says **FEMA assigns flight areas** in coordination with governments, and that mosaicked imagery is composed from several images and **exact tile image time is unavailable** through the viewer. NOAA's own 2018 response account documents collecting 9,580 Michael images during 2018-10-11–14. Such coordinated planning is **potential workflow/source dependence**, NOT a verified statement that FEMA labelled `DR-4399` from the exact NOAA TIFF in the current pilot.

## Evidence levels and exact blocking questions

- **Known original provider image/asset identities:** NOAA original GeoTIFF `20181011aC0853300w302100n.tif` has actual range-verified TIFF/alpha bytes (see separate original receipt). Alternative **NICB/GIC/Vexcel** has only an original public 2018 publisher report, *not a scene/asset byte receipt*.
- **FEMA true-source `DR-4399/RS/WI`:** `IMG_DATE` and `PROD_DATE` are both **null for all 23,682 source records** in the original public aggregate. A label's original image URL/date/producer is *unknown* even if several layers were visible in the historical FEMA dashboard. The public layer's last editing timestamp is 2021-06-22, not source capture time.
- **Dated building identity:** UF `PARCELS_2017` provides **dated parcel context**; not one building per parcel and no known 2018 roof polygon or proven point-in-building identity. UF `PARCELS_2018` can contain post-event information; do not call it pre-event roof stock or structural vulnerability ground truth.
- **Independent observational damage:** NICB imagery is post-event remote-sensing *image evidence* subject to rights and possible source leakage. xBD similarly may overlap same post-event image collections and its own license requires review. Independently field-assessed property-level structural/wind damage with matching event, time and reviewable sampling is still **not established**.
- **Privacy/security:** no names, addresses, owner identifiers, parcel IDs, FEMA feature records or insurer policy details in the register; only dataset-level official metadata and a tiny original pilot. Preserve bounded source IDs, projection/CRS, exact source license, data vintage, lineage and admission flags when original files are eventually acquired.

## Implemented, deterministic, fail-closed source gate

`research_runners/florida_michael_source_vintage_v0.py` validates exactly five fixed metadata identities (FGDL 2017/2018, NOAA Michael imagery, NICB/GIC imagery and FEMA historical remote-sensing layer), enforces coherent source date intervals, detects a content interval crossing the event, rejects unsupported raw feature/owner fields, rejects a parcel polygon relabelled as a building footprint, and refuses positive unverifiable claims of source-image/FEMA linkage. `reconcile_source_family` differentiates **2017 pre-event parcel candidate** from **2018 mixed event-vintage**, and keeps image label independence, original data bytes, exact building identity and CAT-model admission **false**. Source date/flag inputs remain caller-supplied and are **not authenticated by the offline gate**.

`tests/test_florida_michael_source_vintage_v0.py` uses only **synthetic source-shaped metadata** with valid and deliberately invalid dates, duplicate source IDs, owner/address leakage and false independent-image/roof assertions. This is deliberately **not** an importer, public parcel download, FEMA point spatial join, image trainer or production access entitlement.

**Prioritized next bounded evidence:** search exact Bay County **2017 parcel archived package ID and access conditions**, then a pre-2018 separately versioned building footprint with roof geometry; separately identify **specific** GIC/NOAA 2018 image scene(s) originally used by FEMA for `DR-4399` `RS/WI` (if still available and lawful), rather than interpreting provider names or dashboard layer menus as label lineage. Without this chain, no damaged building count, CAT vulnerability calibration, synthetic insurer claim or monetary damage should be admitted.
