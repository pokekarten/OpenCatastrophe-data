# Search-plugin discovery: additional global CAT model inputs — 2026-11-02

## Purpose and scope

Follow-up discovery for a global, multi-peril, insurance-capable CAT modelling stack. Searches used Exa research search, official upstream provider documentation, public datasets, and targeted GitHub code search against `pokekarten/OpenCatastrophe-data` on `main` on 2026-11-02. **This is a research note and candidate inventory, not source admission, a live endpoint probe, a downloaded original-data receipt, a data-rights determination, or a Neon database ingest.** Existing repository products are not asserted to be absent merely because an exact-string code search returns zero results.

Target components: event sets/frequency, hazard intensity grids, exposure attributes, vulnerability/damage, observed impacts, provenance and validation. Terms and commercial use remain **unknown until independently cleared for most candidates**. Smithsonian GVP explicitly restricts commercial use without prior written permission; see the separate canonical source/access records below. No API secrets or third-party bytes are included.

## Existing products intentionally **not** re-registered

- GHSL **GHS-OBAT** and GHS-AGE: already in `landscape/sources-eu-risk-research.json`, plus GHS-OBAT access contract. Use to enrich Overture building attributes; do not count again.
- **OpenBuildingMap**, **JRC global river flood maps**, **GEM Global Vulnerability/Exposure** families: already referenced in landscape/research; version-level follow-up is worthwhile, but product identity is not new.
- **NASA LHASA** and **COOLR**, **Global Fire Atlas**, **GDIS / Geocoded Disasters**: existing registry or documentation mentions found in targeted GitHub search. GDIS is an *EM-DAT-derived geocoding layer*, so not independent post-event damage evidence.
- Existing **NASA FIRMS, EFFIS/GWIS, IBTrACS, World Monitor** and WFP ADAM candidates: lineage-aware links only; do not register a duplicate merely because a different dashboard provides them.
- Vendor/industry historical insured loss datasets (Munich Re NatCatSERVICE, PERILS, CRESTA CLIX, PCS): useful external benchmarking candidates, **not freely reusable bulk records**; avoid claiming downloads or commercial automation rights.

## Priority pilot plan and machine-admission gates

1. **P0: ENSO/event-set research.** Obtain only public metadata, README and per-file checksums for IH-STORM/Zenodo; compare sample structure to IBTrACS and our event schema; model tracks are synthetic, not measured frequencies. Record exact licence before any data import.
2. **P0: Historical hazard footprint.** Identify the exact publicly accessible ISIMIP/COMPASS netCDF filelist, map storm IDs and grids into hazard-event/footprint tables, run variable-unit and missing-value guards. Modelled wind/rain/sea surge is distinct from direct observations.
3. **P0: Fire driver.** After exact terms review and admission to a bounded probe only, perform a header read of NASA GFWED NetCDF, time coverage and longitude wrap; compare FWI with NASA FIRMS fire points *as separate kinds of evidence*, not two independent fire ground-truth data sets.
4. **P1: Missing peril observations.** Do **not** query Smithsonian WFS until prior written commercial permission is secured; separately review Philippines SWAP DR4 metadata; build volcanic site/eruption keys and severe-weather observation confidence fields. Explicitly flag incomplete reporting coverage.
5. **P1: Post-event validation.** Inspect BRIGHT canonical publisher/labels and licensing. Crosswalk events to geographically precise building polygons and documented remote-sensing damage states **without inferring insured TIV, indemnity or ground truth**.
6. **P1: Consolidation.** WorldFires event geometry API may reduce adapter work, but persist original EFFIS/GWIS/FIRMS provider and field lineage and do not duplicate underlying detections.
