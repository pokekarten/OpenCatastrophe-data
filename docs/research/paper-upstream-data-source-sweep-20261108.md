## 2026-11-08 additional scientific-source findings

### CFDID: original document sources, release reconciliation, nested impacts

- **Peer reviewed, published 2026-11-05:** https://doi.org/10.5194/essd-18-8129-2026 . **Original dataset v1.1 released 2026-09-23:** https://zenodo.org/records/22918521 ; it fixes selected event/date values and adds source metadata, README, data dictionary, code, annual benchmarks and an EM-DAT event crosswalk. Do **not** substitute Zenodo v1.0 https://zenodo.org/records/21699973.
- **Three primary official source families:** *China Water Resources Yearbook* (event reporting 1994–2018), *Yearbook of Meteorological Disasters in China* (since 2002), and yearly government *Top Ten Natural Disasters in China* (since 2005). The *China Flood and Drought Bulletin* partially reports the same yearbook statistics and must not be considered a fourth independent loss sample. Some original annual documents require purchase/library access.
- **1,716 hierarchical records:** 1,391 L1 parent events, 300 nested L2, 25 nested L3. For original national/annual impact aggregation sum only compatible L1 parents; L2/L3 must not be added again. Preserve parent/child keys for local analysis. Some events include multiple provinces, missing exact dates/values or non-flood components; not physical hazard footprints or insured losses.
- **Scientific version trap:** the preliminary EGU26 abstract https://doi.org/10.5194/egusphere-egu26-9099 discusses a different claimed 1949–2023 / >15,000 event scope, while the peer-reviewed release is explicitly 1994–2023 / 1,716. They must **not** be merged as one version or treated as empirical confirmation of additional released rows.
- **Next feasible original check:** metadata-only list v1.1 files, licenses and checksums, inspect the original code/dictionary and test event-parent and ISO date rules with independently synthetic rows before any permitted research import. Official yearbook access/rights are distinct from the Zenodo release rights.

### Global flood event linking: Keeney and Davenport, 2026 preprint

- https://doi.org/10.5194/essd-2026-577 is **under review**, not a finalized peer-reviewed publication. It links 4,073 source EM-DAT inland floods to 23,334 administrative-region × month records across 177 countries using MODIS flood extents and a gridded population model.
- Versioned public **code** package https://zenodo.org/records/17905100 includes a ~42.6 MB archive, scripts, small derived CSVs and **four illustrative** GeoTIFF floodmaps. The provider says the **complete** floodmap outputs will be distributed separately; do not claim that the full multi-event raster archive is currently downloadable.
- The underlying **EM-DAT original event IDs** are indispensable, and any GFID, GDIS, DFO or EM-DAT-derived source comparing the same event is not independent loss ground truth. Region/month disaggregation and MODIS-derived inundation are model-dependent approximations.

## Caveat for insurance modelling

Damage observations, hazard footprints, synthetic simulations, hydrological forcing, asset exposure and paid insurance claims have **different scientific roles**. Even high-quality flood surveys do not directly provide insured ground-up loss, policy deductible, TIV, OEP/AEP or annual-frequency calibration. Combine them only under explicit peril, geography, time, units, license, leakage and independence controls.
