# Contributing

Use public Issues and pull requests. Choose the most specific Issue Form and never paste confidential or restricted content into GitHub.

For non-trivial work: re-check current `main`, keep one bounded change, follow `AGENTS.md`, add tests/evidence, run `python scripts/check_all.py`, then open a PR. One accepted PR should become one `main` commit via squash merge.

Source proposals start metadata-only. Scientific and rights uncertainty must remain visible and blocking where appropriate.
