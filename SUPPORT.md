# Support

Use public Issues for reproducible bugs, metadata-only source proposals, scientific questions and bounded agent tasks. Check existing Issues first and run `python scripts/check_all.py` for repository behavior.

Do not publish credentials, confidential/customer/claims/portfolio data, restricted dataset bytes, proprietary model assets, screenshots of restricted systems or private repository/chat content. Security-sensitive reports belong in GitHub's private vulnerability reporting flow.
