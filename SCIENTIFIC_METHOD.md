# Scientific method

Scientific claims must be traceable to public evidence or reproducible computation. A licence PASS is not scientific validation.

For each source or transformation make units, coordinate reference system, temporal semantics, coverage, resolution, quality flags, missingness, uncertainty, transformations and known limitations explicit. Separate source facts from interpretation and project design choices.

Prefer deterministic checks, reference comparisons and falsifiable tests. Do not claim compatibility with an external standard or dataset version without naming the exact version/profile and evidence.

When evidence is incomplete, record uncertainty instead of silently filling gaps.
