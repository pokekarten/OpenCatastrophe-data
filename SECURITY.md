# Security and sensitive-data reporting

This repository is public. Treat Git history, Issues, PRs and Actions logs as publicly visible.

Do not disclose vulnerabilities, credentials, customer/claims/portfolio data, restricted datasets, private endpoints or signed URLs in a public issue. Use GitHub Private Vulnerability Reporting when enabled.

If sensitive material is exposed, revoke or contain the underlying secret/data access first. Deleting a later commit does not undo prior public exposure.

Current `main` is the only supported pre-alpha state; there is no stable release line yet.
